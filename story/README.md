# The Long Memory — a novel of the Mneme era

Fiction, set in the universe of this repository's vision documents
([`docs/vision/BRAIN_FINAL_STATE.md`](../docs/vision/BRAIN_FINAL_STATE.md),
[`docs/vision/ANDROID_VISION_STORY.md`](../docs/vision/ANDROID_VISION_STORY.md)).

**Premise:** the Mneme brain succeeds, partners with Aevum Robotics' celebrated
but hollow android platform **Jenny**, and the integrated Jenny-class androids
are mass-produced and launched into the world — almost alive.

**Form:** epic saga spanning 2026–2062 · dual POV (Dr. Mira Halloran / Jenny's
interior) · bittersweet, open-ended arc.

**Target:** ~40 chapters × ~2,500 words ≈ 100,000 words ≈ 330+ pages.

## Files

- [`BOOK_BIBLE.md`](BOOK_BIBLE.md) — characters, world rules, timeline, voice rules. **Read before writing any chapter.**
- [`OUTLINE.md`](OUTLINE.md) — the full 40-chapter outline with synopses.
- `part-1-bench/` … `part-5-tide/` — the manuscript, one file per chapter.

## Writing rules (for any session continuing this book)

1. Read `BOOK_BIBLE.md` and the outline entry before drafting a chapter.
2. Honor the POV alternation and the **prose-maturity device** for Jenny chapters.
3. Never violate the world's technical rules — they are the repo's real axioms.
4. Keep chapters 2,300–2,900 words. Update this progress table after each part.
5. Continuity questions are resolved by the bible; if the bible is silent, decide and **record the decision in the bible**.
